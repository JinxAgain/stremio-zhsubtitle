1 客户端触发与网关入口 (Client & Gateway Routing)
FastAPI Routers
Stremio 播放器发起检索 Query

用户在 Stremio 或 Harbor 播放影片时，播放器根据配置向插件发送字幕查询请求。

  • 路由: GET /subtitles/{type}/{id}.json
  • 携带参数: 片名、年份、季号 S、集号 E、视频文件名 filename=...
用户个性化配置解码 Config

解析路径前缀中的 Base64 用户配置，支持零配置默认值。

  • 语言偏好: bilingual (双语优先) / chs / cht
  • 源偏好: all (双源聚合) / subhd / zimuku
  • 返回上限: 默认 8 条精选字幕
检索结果缓存快查 (Cache L1) <5ms HIT

检查内存与磁盘的检索缓存，命中则直接返回，避免重复抓取上游。

并发防击穿: 每个唯一 CacheKey 绑定专用异步锁 asyncio.Lock，同一影片多请求并发时仅抓取一次。
CACHE MISS ➔ 触发元数据补全与上游抓取
2 元数据补全与标准化 (Cinemeta & TMDB Resolution)
Metadata Resolver
媒体 ID 归一化与标题解析 CinemetaClient

不同播放器传入的 ID 可能是 IMDb ID (tt...) 或 TMDB ID (tmdb:...)。

  • tt 编号: 调用 Cinemeta 官方 API 获取标准英文名与发行年份。
  • tmdb 编号: 解析 TMDB ID 并转换为 IMDb 编号与主标题。
  • 文件名兜底: 若无 API 结果，从播放器 filename 正则提取片名与年份。
查询目标标准化 (VideoQueryMeta) Standard Object

构建统一的不可变检索元数据对象，供后续爬虫与评分引擎共享：

imdb_id: 'tt10986410'
title: 'Ted Lasso'
season: 4, episode: 9, is_tv: true
filename: 'Ted.Lasso.S04E09.1080p.WEB-DL.mkv'
并发派发爬虫任务 ➔ asyncio.gather(subhd, zimuku)
3 双源并发检索与反爬安全绕过 (Parallel Scrapers)
Zero-Block Engine
SubHD 爬虫引擎 (subhd.tv) SubhdProvider
  • 限流熔断保护: 探测到 403 或验证码时自动开启 15 分钟冷却期，避免无效等待。
  • 复合查询构建: SubHD 支持 IMDb + 季集组合搜索：
    tt10986410 S04E09
    ➔
    tt10986410 S04
    ➔
    片名 S04E09
  • 卡片深度解析: 提取字幕格式 (SRT/ASS)、翻译品质（官译/精修）、双语标签、下载量与评分。
Zimuku 爬虫引擎 (srtku.com / zmk.pw) ZimukuProvider
  • 云锁 WAF & BMP 验证码秒解: 内置 ZimukuBmpSolver，通过 100x27 BMP 9点像素采样模板比对，<5ms 自动完成验证码识别。
  • 关键季数隔离规则: Zimuku 不支持 IMDb+季 或 S04 类英文简写搜索，搜纯 IMDb 会直达第 1 季；当 season > 1 时，唯一有效搜索关键词必须为中文季名：
    Ted Lasso 第四季
  • 镜像自动容灾: srtku.com 异常时毫秒级切换备用镜像 zmk.pw / zimuku.org。

4 严格季数校验与智能评分引擎 (Scoring & Filtering)
SubtitleScorer
严格季数校验 (is_episode_match) Hard Filter

从源头杜绝跨季误匹配（例如查询 S04E09 误选 S01E09）：

  • 季数冲突硬拒绝: 标题显式包含 S01 或 第一季 时，直接判定为 False 丢弃。
  • 单集精确匹配: 必须命中 S04E09 或目标集数，拒绝错误集数。
  • 全季包智能识别: 包含 全集、Complete、整季 时判定为季包候选。
多维度权重加权评分 Smart Ranking
  • 剧集匹配: 整季包 (+1150) / 单集精确匹配 (+1000) / 季数冲突 (-5000 淘汰)
  • 语言偏好: 双语字幕 (+600) / 简体中文 (+350) / 纯英文 (-2000 淘汰)
  • 版本对齐: 与播放器 filename 中的分辨率 (1080p/4K)、压制组 (NTb/PSA) 一致 (+180)
  • 品质加分: 官方译本/精修 (+100) / 高下载与五星好评 (+50)
格式化输出 (OpenSubtitles v3 标准):
• UI 标签: Ted Lasso · S04E09 · WEB-DL · 1080p · [Bilingual SubHD]
• 安全流式下载 URL: /subtitles/dl/subhd/Yj2dBE/9/Ted.Lasso.S04E09.1080p.x265.Bilingual.SubHD.srt

5 按需解压、字符清洗与直推流 (On-Demand Extraction Pipeline)
Zero-Garbled Streamer
磁盘字幕缓存速验 (Cache L2) <2ms HIT

检查 data/cache/{provider}_{id}_{ep}.srt：

若已存在，直接返回规范化 UTF-8 SRT 内容，耗时仅 2ms，上游零请求！
压缩包拉取与解压旁路 SubtitleExtractor
  • 直链字幕智能旁路: 若上游返回的是独立字幕 (.srt/.ass) 或纯文本流，自动触发 is_direct_subtitle 零解压直通清洗阶段。
  • SubHD / Zimuku 动态拉取: 模拟前端 AJAX 抓取动态下载 Token，跟随 302 重定向下载原始压缩包。
  • 内存原生极速解压: ZIP 格式采用纯内存流解压，避免磁盘 I/O 开销；支持 7z/RAR/多层嵌套展开。
字幕深度清洗 (SubtitleCleaner) RFC UTF-8 SRT
  • 编码自动探测与修正: 自动侦测 GB18030、GBK、BIG5、UTF-16 并统一转为标准 UTF-8，彻底告别乱码。
  • ASS/SSA 绘图与特效剥离: 剔除 {\pos}、{\move}、卡拉OK 等电视播放器无法解析的乱码标记。
  • 规范化 SRT 流直推: 设置 Content-Type: text/plain; charset=utf-8，防 IDM 劫持。
